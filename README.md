# cAr LovER’s — Verified Bangladeshi Car Marketplace

## Included Files
- `index.html` — Complete, self-contained web application (HTML, Tailwind CSS, SVG Brand Logos, and JavaScript).
- `manifest.json` — Progressive Web App (PWA) manifest for Android/iOS home-screen installation and PWABuilder APK packaging.

## How to Run Locally
1. Extract this ZIP archive into a folder.
2. Double-click `index.html` to open it in any modern web browser (Chrome, Edge, Safari, Firefox).

## How to Convert into an Android `.apk`
1. Host the extracted folder on any static host (e.g., GitHub Pages, Netlify, or Vercel) to get an HTTPS URL.
2. Open **PWABuilder.com**, paste your HTTPS URL, and click **Start**.
3. Select **Package for Stores -> Android** and download your `.apk` package.
